# Arte das animações

`kirin-beast.png` é um sprite com canal alfa, gerado com a ferramenta imagegen em 23/10/2026 para a cena de Kirin. A referência visual foi `externalAssets/Kirin.png`, fornecida pelo jogador, e a direção solicitada foi o jutsu Kirin do Sasuke, de Naruto.

A cena PixiJS anima a aparição, descida e dissipação dessa fera; descargas, céu e impacto são desenhados em tempo real. O sprite é independente do ícone do catálogo.

O arquivo é parte do projeto e funciona offline. Não foi extraído de um episódio ou jogo.
